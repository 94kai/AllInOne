# allinone

面向个人 NAS 的统一入口。提供移动端优先的系统概览、文件管理器与可维护的地址导航。

## 已实现

- 默认进入系统 Home，在多个受控根目录之间切换、进入子目录、面包屑返回，并可确认后永久删除文件或文件夹
- 默认隐藏名称以 `.` 开头的文件和目录，可通过文件页工具栏切换显示
- 一键复制当前目录、文件或子目录在服务器上的绝对路径
- 收藏任意受控目录，并通过文件页顶部快捷栏快速进入
- 列表/网格布局，以及图片、音频、视频、PDF 和常见源码/配置/日志/字幕文本在线预览
- 支持 Range 的文件播放与下载
- CPU、内存、CPU 温度以及每块物理硬盘的用量/温度按需读取，不运行常驻采集任务
- 概览页紧凑地址导航，支持点击跳转、右侧按钮编辑、拖动排序，以及本地图标、自定义图片 URL 或首字颜色图标
- 导航链接可保存最多 2000 字符的可选备注
- 网络测速模块，可真实测试当前浏览器到 Allinone 服务器的上传和下载速度，并支持中途停止
- ShellCrash 网络守护，通过 ChatGPT HTTPS 连通性检测当前节点，连续失败后自动切换到可用的最低延迟节点，并支持状态查看和手动切换
- 独立出行清单，支持快速添加、划掉和恢复条目、一键全部恢复、拼音排序及触控拖动自定义排序
- 进京证状态查询，优先使用状态接口直查，状态 Auth 失效时自动使用 JWT 换取新值并重试
- 移动端优先的真实终端，支持完整内置 QWERTY/符号键盘、Vim 快捷键栏、组合键、tmux 命名会话、断线重连、字号调整和安全多行粘贴
- 独立“小爱同学”入口，默认向指定音箱直接播报，也可发送自然语言指令；保留每台音箱最近 5 条历史，点击历史会回填编辑框并立即重播，支持配置灯光、空调、场景等一键快捷控制
- 统一音乐入口，通过“小爱播放 / 音乐下载”切换：播放侧采用响应式家庭音乐控制台，管理两台音箱及本地曲库，支持实时队列、持久播放列表、搜索后单首/批量加入、我喜欢、单曲或列表按指定轮数播放和 0–100 音量控制；下载侧支持聚合搜索、异步下载、在线试听、确认删除、批量移动和音频元信息刮削
- 统一的中性轻量视觉系统、手机悬浮底部导航、底部预览抽屉、安全区域和桌面侧栏布局

## 启动

需要 Node.js 20 或更高版本，首次运行先执行 `npm install`。网页终端还需要系统安装 `tmux`，`node-pty` 安装时需要本机 C/C++ 编译环境。

小爱音乐模块还需要系统提供 Python 3 和 `ffprobe`。音乐核心与小爱 WebSocket/RPC 协议均已包含在当前项目中，不再依赖原来的 `XiaoAiMusic`、`XiaoAiMusicForNew` 目录；两个旧 PM2 应用也不需要再启动。

音乐下载模块需要 `ffmpeg`。首次搜索时会按当前系统自动下载 `media-get 0.2.14` 到 `data/music-download/bin/`；也可通过 `MUSIC_MEDIA_GET_PATH` 使用自行安装的可执行文件。登录网易云后可选择极高、无损、Hi-Res 或超清母带音质，搜索和下载使用账号实际拥有的权益；二维码被平台风控时可导入网页版中包含 `MUSIC_U` 的 Cookie。Cookie 使用 `NETEASE_COOKIE_SECRET`（未配置时回退 `DEVSTUDIO_TOKEN`）派生的密钥加密保存在模块数据目录，前端不会读取明文。未登录及其他音乐来源继续使用 `media-get`。默认歌曲保存在 `data/music-download/downloads/`，可通过 `MUSIC_DOWNLOAD_DIR` 修改。批量移动时可浏览目的地已有子目录并逐级选择，也可手动输入尚不存在的目录让系统自动创建。

```bash
cp .env.example .env
# 按实际情况修改 .env 后，将其中变量加载到当前 shell
set -a; source .env; set +a
npm start
```

访问 `http://127.0.0.1:2006/`。服务默认监听 `0.0.0.0:2006`，同一局域网的手机可以通过 `http://Mac的局域网IP:2006/` 访问。

主导航支持通过 `?view=` 直接打开并自动切换，例如把 `http://127.0.0.1:2006/?view=terminal` 保存为书签即可直达“终端”。可用值为 `home`、`files`、`speed`、`checklist`、`beijing-pass`、`shellcrash`、`terminal`、`xiaoai` 和 `music`。

## ShellCrash 网络守护

“网络守护”读取服务器上的 ShellCrash/Mihomo 控制接口，默认每 3 分钟使用当前节点访问 `https://chatgpt.com/cdn-cgi/trace`。连续失败 3 次后，模块并发测试当前代理组中的真实节点，切换到能够访问检测地址且延迟最低的节点；切换后冷却 10 分钟，避免线路抖动造成频繁切换。页面可调整检测间隔、失败阈值和冷却时间，也可立即检测或二次确认后手动切换节点。

默认从 `/etc/ShellCrash/config.yaml` 读取 `external-controller`、`secret` 和 `mixed-port`；其他安装位置可通过 `SHELLCRASH_CONFIG_PATH` 指定。控制密钥只在服务端内存中使用，不写入模块数据，也不返回浏览器。守护设置、失败计数及最近 30 条记录保存在 Git 忽略的 `data/shellcrash/state.json`。若 ShellCrash 未安装或控制接口不可用，只会在本模块显示错误，不影响其他功能。

## 进京证

进入“进京证”Tab 时会自动完成一次状态查询和办理资料读取；之后只在点击“查询进京证”或“重新读取”时刷新，进入页面不会启动定时查询。

查询结果顶部显示本次服务端实时请求的完成时间，便于区分刷新后的结果和页面中保留的旧结果。

进入“进京证”Tab 后点击“查询进京证”。结果按车辆展示车牌、办理状态、有效期、类型、申请时间、证号、驾驶人及剩余次数等信息，不直接显示原始 JSON。“办理准备”可读取车辆详情和驾驶人信息，选择车辆、六环内外及计划日期后，以服务器私有固定目的地生成申请摘要并二次确认提交。服务端提交前重新检查办理中/生效中状态和对应类型资格；请求只发送一次，超时后不会自动重试。提交成功后会创建仅存于当前进程的轮询任务，每分钟查询一次、最多 15 次；取得非“审核中”结果后立即停止并通过 Server酱推送，15 次后仍无最终结果或接口持续失败也会推送并停止。普通查询不会创建任务，服务重启不会恢复任务。可在接口配置填写 Server酱 SendKey，或通过 `BEIJING_PASS_SERVERCHAN_SENDKEY` 设置。固定目的地保存在 Git 忽略的 `data/beijing-pass/apply-defaults.json`。接口调用链默认折叠，展开后可查看状态查询和 JWT 换取两个接口、脱敏凭据、本次步骤状态和最终使用路径。服务先使用当前状态 Auth 调用状态接口；失败时使用 JWT 调用 `getSsoUserToken`，将响应 `data` 保存为新状态 Auth 后重试。页面“接口配置”只读展示两个固定接口地址，方便以后按地址抓包；状态 Auth、JWT 和 SendKey 可编辑。真实凭据仅保存于 Git 忽略的 `data/beijing-pass/config.json`，文件权限由模块保存时收紧为 `0600`，不要将其提交或分享。

DevStudio 托管预览 `https://devstudio.xuekai.top:8888` 会请求 `https://aio.xuekai.top:8888` 下的接口。本地 Preview 运行在 `8787` 时，前端自动连接同一主机的 `2006` 端口；直接访问则使用同源接口。

未配置 `FILE_ROOTS` 时默认开放并进入运行用户的 Home 目录。配置多个目录的格式如下：

```env
FILE_ROOTS=照片:/Volumes/NAS/Photos,音乐:/Volumes/NAS/Music,电影:/Volumes/NAS/Movies
```

当前服务器已配置 `Home` 和 `xuekai-master` 两个文件入口。

## 访问令牌

在项目根目录的 `.env` 中设置长度充足、随机且独立的令牌：

```env
DEVSTUDIO_TOKEN=replace-with-a-long-random-token
```

重启 `npm start` 后生效。浏览器访问会进入 `/login`，登录状态保存 30 天；访问 `/logout` 可退出。API 可使用登录 Cookie 或 `Authorization: Bearer <token>`，iframe 等无法添加请求头的必要场景可使用 `?token=<token>`。URL 会泄露到历史记录和代理日志，应优先使用 Cookie 或 Bearer。

留空或删除 `DEVSTUDIO_TOKEN` 时保持无认证模式。`.env` 已被 Git 忽略，不要将真实令牌写入源码、文档或 `.env.example`。更换令牌并重启后，旧登录 Cookie 会自动失效。

## PM2 常驻运行

服务器上由 PM2 管理 `allinone` 进程，配置位于 `ecosystem.config.cjs`。修改代码或 `.env` 后使用：

```bash
npm run pm2:restart
```

常用命令：

```bash
npm run pm2:start
npm run pm2:stop
npm run pm2:logs
pm2 status
```

PM2 已保存当前进程列表；系统启动时由 `pm2-xuekai.service` 恢复。若以后增删 PM2 应用，需要再执行 `pm2 save`。

小爱音乐的两个 worker 现在由 `allinone` 进程统一管理，不再作为独立 PM2 应用运行。Allinone 停止或重启时会同步安全停止、恢复两个 worker。

## 出行清单

进入“清单”Tab 后可连续添加出门需要携带的物品，并选择通用、爸爸、妈妈或赞赞。手机滚动时，总数、已选择数、添加栏和人员筛选作为同一区域吸顶，可随时查看当前人员进度或新增条目；条目右侧下拉框可改变归属。点击圆形勾选按钮或条目文字可划掉，再次点击即可恢复；开启置顶时条目会先在原位显示完成反馈，再移动到顶部。最近 10 个划掉的项目显示数字序号，`1` 代表最近一次，刷新页面后仍可辨认。每次准备出门时点击“全部取消划掉”即可开始新一轮确认。排序方式和“划掉的置顶”开关保存在当前浏览器：拼音排序使用中文拼音规则即时展示，自定义排序会持久化到服务端，手机和桌面均可按住条目右侧把手拖动调整。

## 网页终端

在 `.env` 设置 `TERMINAL_ENABLED=true` 并重启服务后，进入“终端”Tab 即可使用。默认会话名为 `main`；新建或切换会话时，后台使用 `allinone-<名称>` 对应的 tmux 会话，因此刷新网页、锁屏或临时断网不会结束其中的程序。关闭会话会同时终止该 tmux 会话，页面会在操作前确认。

终端采用沉浸式全屏，顶部左侧返回按钮可退出终端并恢复主导航；退出页面只断开当前网页客户端，不会结束 tmux 会话中的任务。

手机和平板使用页面内的完整 QWERTY 键盘，不再唤起系统键盘。默认层按电脑键盘排列，Q、A、Z 三行逐级向右错位，Ctrl 位于 A 左侧，并直接包含 `` ` - = [ ] ; , . / ``，Shift 后得到对应上档符号；同时提供 Ctrl/Alt 一次性组合键、Tab、空格、回车、退格和方向键，退格及方向键可以长按连发。上方保留常用 Vim 命令快捷栏。单指在终端内上下拖动可浏览回滚内容。多行剪贴板内容发送前会确认，并使用终端的 bracketed paste 边界；桌面端仍可直接使用物理键盘。字号与上次会话保存在当前浏览器。

可选配置 `TERMINAL_CWD` 指定新会话工作目录，未设置时使用第一个 `FILE_ROOTS`；`TERMINAL_MAX_SESSIONS` 默认为 8。终端继承 Allinone 进程用户的系统权限，不应将服务直接暴露到公网，建议使用 HTTPS、访问令牌和反向代理限速。

## 模块扩展

音乐下载、小爱同学音乐播放等功能均以独立模块实现，不与概览、文件和导航的内部状态混用。每个模块拥有独立的前端代码、API 命名空间、数据目录和错误边界；只复用鉴权、通用 UI 和安全校验等公共基础能力。详细边界见 `doc.md`。

## 安全提示

当前仅提供共享访问令牌，不是多用户账号系统，也没有暴力破解限速。不要把 2006 端口直接暴露到公网；对外部署应启用 HTTPS，并在反向代理层增加限速或访问控制。文件管理器可永久删除受控目录内的内容，网页终端还拥有运行用户的完整 Shell 权限。

更完整的架构与接口说明见 [doc.md](./doc.md)。
