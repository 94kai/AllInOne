# allinone

面向个人 NAS 的统一入口。提供移动端优先的系统概览、文件管理器与可维护的地址导航。

## 已实现

- 默认进入系统 Home，在多个受控根目录之间切换、进入子目录、面包屑返回，并可新建文件夹、向当前目录批量上传或确认后永久删除文件和文件夹
- 默认隐藏名称以 `.` 开头的文件和目录，可通过文件页工具栏切换显示
- 一键复制当前目录、文件或子目录在服务器上的绝对路径
- 文件页路径下拉框旁的“配置”支持添加、修改、删除和排序快捷根目录，保存后立即生效并持久化
- 收藏任意受控目录，并通过文件页顶部快捷栏快速进入
- 列表/网格布局，以及图片、音频、视频、PDF 和常见源码/配置/日志/字幕文本在线预览
- 支持 Range 的文件播放与下载
- 可发送 HTTPS 文件查看链接：登录后返回原文件，CSV 支持表格、搜索、分批显示和下载，避免把服务器绝对路径当成浏览器链接
- CPU、内存、CPU 温度以及每块物理硬盘的用量/温度按需读取，不运行常驻采集任务
- 概览页紧凑地址导航，支持点击跳转、右侧按钮编辑、拖动排序，以及本地图标、自定义图片 URL 或首字颜色图标
- 导航链接可保存最多 2000 字符的可选备注
- 网络测速模块，可真实测试当前浏览器到 Allinone 服务器的上传和下载速度，并支持中途停止
- 账单管理首版可解析记账软件账单模板与微信账单，并按代码中的固定规则展示源数据和导出预览
- 健康数据 Tab：按人员管理健康档案，支持添加人员、列表展示、自定义显示列、新增/编辑记录及导出 XLSX，数据保存在独立 SQLite 数据库
- 独立出行清单，支持快速添加、划掉和恢复条目、一键全部恢复、拼音排序及触控拖动自定义排序
- 进京证状态查询，优先使用状态接口直查，状态 Auth 失效时自动使用 JWT 换取新值并重试
- 移动端优先的真实终端，支持一键切换原生键盘（可输入中文）与完整内置 QWERTY/符号键盘、Vim 快捷键栏、组合键、tmux 命名会话、断线重连、字号调整和安全多行粘贴
- 独立“小爱同学”入口，默认向指定音箱直接播报，也可发送自然语言指令；保留每台音箱最近 5 条历史，点击历史会回填编辑框并立即重播，支持配置灯光、空调、场景等一键快捷控制
- 统一音乐入口，通过“小爱播放 / 音乐下载”切换：播放侧采用响应式家庭音乐控制台，管理两台音箱及本地曲库，支持实时队列、持久播放列表、搜索后单首/批量加入、我喜欢、单曲或列表按指定轮数播放和 0–100 音量控制；下载侧支持聚合搜索、异步下载、在线试听、重命名、确认删除、批量移动和音频元信息刮削
- 统一的中性轻量视觉系统、手机悬浮底部导航、底部预览抽屉、安全区域和桌面侧栏布局

## 启动

需要 Node.js 20 或更高版本；健康模块使用内置 SQLite，需要 Node.js 22.13 或更高版本（推荐使用此版本或更高版本运行整个项目）。首次运行先执行 `npm install`。网页终端还需要系统安装 `tmux`，`node-pty` 安装时需要本机 C/C++ 编译环境。

小爱音乐模块还需要系统提供 Python 3 和 `ffprobe`。语音同音字匹配使用 `pypinyin`，在项目根目录执行 `python3 -m pip install --no-cache-dir --no-deps --target data/xiaoai-music/python-deps -r modules/xiaoai-music/requirements.txt` 安装；若设置了 `XIAOAI_PYTHON`，请使用该解释器运行安装命令。音乐核心与小爱 WebSocket/RPC 协议均已包含在当前项目中，不再依赖原来的 `XiaoAiMusic`、`XiaoAiMusicForNew` 目录；两个旧 PM2 应用也不需要再启动。

音乐下载搜索仅展示歌名包含完整关键词的结果（忽略英文大小写，保留关键词内部空格），可输入部分歌名，不再按歌手名匹配。默认搜索咪咕、网易云单曲及声音、QQ、酷狗、酷我和 Bilibili；声音标为“网易云声音”，显示上传者与播客名，支持下载及失败后尝试下载，实际音质取决于上传资源；搜索结果区展示配置的来源、公开来源歌名不匹配及全部暂不可下载结果的数量，并提示搜索异常。暂不可下载结果默认保留并标明原因，可点击“尝试下载”重新解析并下载，失败原因显示在下载任务中；点击“一键隐藏不可下载”只看可下载结果，再次点击可恢复显示。

音乐下载模块需要 `ffmpeg`。首次搜索时会按当前系统自动下载 `media-get 0.2.14` 到 `data/music-download/bin/`；也可通过 `MUSIC_MEDIA_GET_PATH` 使用自行安装的可执行文件。登录网易云后可选择极高、无损、Hi-Res 或超清母带音质，搜索和下载使用账号实际拥有的权益；二维码被平台风控时可导入网页版中包含 `MUSIC_U` 的 Cookie。Cookie 使用 `NETEASE_COOKIE_SECRET`（未配置时回退 `DEVSTUDIO_TOKEN`）派生的密钥加密保存在模块数据目录，前端不会读取明文。未登录及其他音乐来源继续使用 `media-get`。默认歌曲保存在 `data/music-download/downloads/`，可通过 `MUSIC_DOWNLOAD_DIR` 修改。批量移动时可浏览目的地已有子目录并逐级选择，也可手动输入尚不存在的目录让系统自动创建。

```bash
cp .env.example .env
# 按实际情况修改 .env 后，将其中变量加载到当前 shell
set -a; source .env; set +a
npm start
```

访问 `http://127.0.0.1:2006/`。服务默认监听 `0.0.0.0:2006`，同一局域网的手机可以通过 `http://Mac的局域网IP:2006/` 访问。

主导航支持通过 `?view=` 直接打开并自动切换，例如把 `http://127.0.0.1:2006/?view=terminal` 保存为书签即可直达“终端”。可用值为 `home`、`files`、`speed`、`checklist`、`beijing-pass`、`bill-manager`、`health`、`terminal`、`xiaoai` 和 `music`。

文件查看链接使用 `/modules/file-manager/open.html?root=<目录ID>&path=<目录内相对路径>`，参数须 URL 编码，并拼接浏览器实际可访问的 Allinone 地址。目录 ID 从文件路径配置读取，不是服务器绝对路径。未登录先进入既有登录页，登录后返回原文件；CSV 支持搜索与下载，其他 UTF-8 文本直接预览。沿用原有文件根目录边界、文本预览大小限制和登录权限，不创建匿名分享。此功能仅新增静态资源，刷新即可使用，无需重启服务，启动仍为 `npm start`、端口 2006。

用户文件交付约定：后续文本、Markdown、JSON、日志、CSV 清单和报告默认发送上述 HTTPS 查看链接，并使用明确的中文标题；不以服务器绝对路径代替可访问链接。网页地址以当前部署配置为准，发送前检查文件存在和接口可读。不能预览或超出大小限制时说明可在页面下载，只有用户明确需要时才另附本地路径。此约定适用于项目全部文件交付，已同步写入 `AGENTS.md`。

## 账单管理

“账单”Tab 支持上传不超过 20 MB 的微信 `.xls`/`.xlsx` 账单、查看转换预览并导出 `.xlsx`。新上传文件会替换当前微信账单。页面没有固定映射编辑控件，规则由代码固定：账单模板不输出“优惠、标签、地址”，“所属账本”固定为“日常账本”；微信“交易类型”不输出，交易时间保留完整日期和时分秒映射到“日期”，金额映射到“金额”，“收/支”映射到“收支类型”，并将支出类别设为“临时支出”、收入类别设为“临时收入”，“商品”和“交易对方”以空格拼接后映射到“备注”，“收支账户”固定为“凯的微信钱包”。源文件位于 Git 忽略的 `data/bill-manager/`。

支付宝 Tab 支持直接上传不超过 20 MB、GB18030 编码的支付宝交易明细 CSV。“支付宝记录”完整保留并只读展示原始记录，默认不过滤任何收付款方式；用户可添加“收付款方式包含指定字符串时排除”的持久化过滤规则，规则仅作用于导出预览和统一导出，不修改源数据。支付宝导出预览按账单模板展示：交易时间保留完整日期和时分秒映射到“日期”，“收/支”映射到“收支类型”，“金额”原值映射，未命中自定义规则时将支出类别设为“临时支出”、收入类别设为“临时收入”，“商品说明、交易对方、交易分类”依次以空格拼接到“备注”，“所属账本”固定为“日常账本”，“收支账户”固定为“凯的支付宝”。

界面隐藏内部模板页，只显示微信、支付宝和招商银行来源，并在各来源的紧凑文件卡片中显示最近上传时间和上传操作；“统一导出”仅在“账单”Tab 的页面标题旁显示，将三个来源的转换结果写入同一个账单工作表，切换到其他 Tab 后隐藏。

“招商银行”Tab 支持上传不超过 20 MB 的招商银行交易流水 PDF。服务端直接提取 PDF 内嵌文字并按坐标还原跨行单元格，完整展示记账日期、货币、交易金额、联机余额、交易摘要和对手信息等原始流水。转换时将记账日期映射到“日期”，根据交易金额正负映射“收入/支出”，金额取绝对值，未命中自定义规则时将收入、支出分别映射为“临时收入、临时支出”，并将“交易摘要、对手信息”以空格拼接到“备注”；“所属账本”固定为“日常账本”，“收支账户”固定为“凯的招商银行”。招商记录已加入统一导出。

微信和支付宝共用可编辑的“备注分类规则”：当最终备注包含指定字符串时覆盖一级分类，并可选填写二级分类。输入匹配字符串时会实时统计当前账单导出预览中的命中条数。规则从上到下匹配，首条命中生效；新规则添加在最上方并持久化到模块数据目录。

账单表格对备注、商品说明等长文本列使用更宽的自动换行布局；任意被截断的单元格可点击展开或再次点击收起。

导出预览可切换“只看临时分类”，快速定位尚未被自定义备注规则覆盖的记录；该筛选只影响页面预览，不改变统一导出的内容。

## 进京证

进入“进京证”Tab 时会自动完成一次状态查询和办理资料读取；页面查询仍按需刷新；服务端另有独立的每日检测任务，不依赖页面打开。

查询结果顶部显示本次服务端实时请求的完成时间，便于区分刷新后的结果和页面中保留的旧结果。

进入“进京证”Tab 后点击“查询进京证”。结果按车辆展示车牌、办理状态、有效期、类型、申请时间、证号、驾驶人及剩余次数等信息，不直接显示原始 JSON。“办理准备”可读取车辆详情和驾驶人信息，选择车辆、六环内外及计划日期后，以服务器私有固定目的地生成申请摘要并二次确认提交。服务端提交前重新检查办理中/生效中状态和对应类型资格；请求只发送一次，超时后不会自动重试。提交成功后会创建持久化审核查询任务，每分钟查询一次、最多 15 次；取得明确的审核成功或失败结果后立即停止并通过 Server酱推送，15 次后仍无最终结果或接口持续失败也会推送并停止。普通查询不会创建审核任务，服务重启会恢复未完成的审核查询。可在接口配置填写 Server酱 SendKey，或通过 `BEIJING_PASS_SERVERCHAN_SENDKEY` 设置。固定目的地保存在 Git 忽略的 `data/beijing-pass/apply-defaults.json`。接口调用链默认折叠，展开后可查看状态查询和 JWT 换取两个接口、脱敏凭据、本次步骤状态和最终使用路径。服务先使用当前状态 Auth 调用状态接口；失败时使用 JWT 调用 `getSsoUserToken`，将响应 `data` 保存为新状态 Auth 后重试。页面“接口配置”只读展示两个固定接口地址，方便以后按地址抓包；状态 Auth、JWT 和 SendKey 可编辑。真实凭据仅保存于 Git 忽略的 `data/beijing-pass/config.json`，文件权限由模块保存时收紧为 `0600`，不要将其提交或分享。

“每日检测”在北京时间每天 **22:00** 检查所选车辆。证件已到期、当天为最后一天或没有有效证件时，开启“自动申请”会尝试申请次日生效的进京证；默认关闭，此时会发送“自动申请未开启”的微信提醒。可选择六环内或六环外（默认六环内），沿用办理准备中的驾驶人和固定目的地。设置更改后自动保存；开启前需选择车辆并在接口配置填写 Server酱 SendKey。未选择车辆时，仅在账号恰好只有一辆车的情况下检测该车，多辆车需明确选择。

“立即检测”会立即执行相同流程，也会按开关提交申请。页面显示下次检测、最近结果和微信发送状态。已有覆盖次日的证件或正在审核的申请时不重复办理；状态不明、查询或提交失败时发送异常提醒。提交成功先发送受理提醒，随后发送最终审核结果或查询超时提醒。官方不允许续办时显示并推送官方原因，不保证申请成功。

自动设置和申请去重记录保存在 `data/beijing-pass/automation.json`，重启后保留。同一车辆、类型和生效日期最多自动尝试一次，超时也不自动重提。服务需持续运行；22:00 后当天重启且尚未检测时补做一次，不补办已过去的日期。更新后执行 `npm run pm2:restart`（普通启动使用 `npm start`），再刷新页面。

DevStudio 托管预览 `https://devstudio.xuekai.top:8888` 会请求 `https://aio.xuekai.top:8888` 下的接口。本地 Preview 运行在 `8787` 时，前端自动连接同一主机的 `2006` 端口；直接访问则使用同源接口。

未配置 `FILE_ROOTS` 时默认开放并进入运行用户的 Home 目录。配置多个目录的格式如下：

```env
FILE_ROOTS=照片:/Volumes/NAS/Photos,音乐:/Volumes/NAS/Music,电影:/Volumes/NAS/Movies
```

当前服务器已配置 `Home` 和 `xuekai-master` 两个文件入口。

文件页工具栏可在当前受控目录新建文件夹，也可一次选择多个文件上传并显示总体进度；同名项目不会被覆盖。单文件默认上限为 10 GiB，可通过 `FILE_UPLOAD_LIMIT` 按字节调整。上传过程采用同目录临时文件，完成后原子落盘，失败或取消会清理临时文件。

音乐下载和音频标签编辑在音乐保存目录内创建隐藏临时目录，完成后原子落盘，支持保存到与系统 `/tmp` 不同的磁盘；临时文件不显示在下载列表中，任务结束后自动清理。

## 访问令牌

在项目根目录的 `.env` 中设置长度充足、随机且独立的令牌：

```env
DEVSTUDIO_TOKEN=replace-with-a-long-random-token
```

重启 `npm start` 后生效。浏览器访问会进入 `/login`，登录状态保存 30 天；访问 `/logout` 可退出。API 可使用登录 Cookie 或 `Authorization: Bearer <token>`，iframe 等无法添加请求头的必要场景可使用 `?token=<token>`。URL 会泄露到历史记录和代理日志，应优先使用 Cookie 或 Bearer。

留空或删除 `DEVSTUDIO_TOKEN` 时保持无认证模式。`.env` 已被 Git 忽略，不要将真实令牌写入源码、文档或 `.env.example`。更换令牌并重启后，旧登录 Cookie 会自动失效。

## PM2 常驻运行

服务器上由 PM2 管理 `allinone` 进程，配置位于 `ecosystem.config.cjs`。修改代码或 `.env` 后使用：

```bash
npm run pm2:restart
```

常用命令：

```bash
npm run pm2:start
npm run pm2:stop
npm run pm2:logs
pm2 status
```

PM2 已保存当前进程列表；系统启动时由 `pm2-xuekai.service` 恢复。若以后增删 PM2 应用，需要再执行 `pm2 save`。

小爱音乐的两个 worker 现在由 `allinone` 进程统一管理，不再作为独立 PM2 应用运行。Allinone 停止或重启时会同步安全停止、恢复两个 worker。

## 出行清单

进入“清单”Tab 后可连续添加出门需要携带的物品，并选择通用、爸爸、妈妈或赞赞。手机滚动时，总数、已选择数、添加栏和人员筛选作为同一区域吸顶，可随时查看当前人员进度或新增条目；条目右侧下拉框可改变归属。点击圆形勾选按钮或条目文字可划掉，再次点击即可恢复；开启置顶时条目会先在原位显示完成反馈，再移动到顶部。最近 10 个划掉的项目显示数字序号，`1` 代表最近一次，刷新页面后仍可辨认。每次准备出门时点击“全部取消划掉”即可开始新一轮确认。排序方式和“划掉的置顶”开关保存在当前浏览器：拼音排序使用中文拼音规则即时展示，自定义排序会持久化到服务端，手机和桌面均可按住条目右侧把手拖动调整。

## 网页终端

在 `.env` 设置 `TERMINAL_ENABLED=true` 并重启服务后，进入“终端”Tab 即可使用。默认会话名为 `main`；新建或切换会话时，后台使用 `allinone-<名称>` 对应的 tmux 会话，因此刷新网页、锁屏或临时断网不会结束其中的程序。关闭会话会同时终止该 tmux 会话，页面会在操作前确认。

终端采用沉浸式全屏，顶部左侧返回按钮可退出终端并恢复主导航；退出页面只断开当前网页客户端，不会结束 tmux 会话中的任务。

手机和平板使用页面内的完整 QWERTY 键盘，不再唤起系统键盘。默认层按电脑键盘排列，Q、A、Z 三行逐级向右错位，Ctrl 位于 A 左侧，并直接包含 `` ` - = [ ] ; , . / ``，Shift 后得到对应上档符号；同时提供 Ctrl/Alt 一次性组合键、Tab、空格、回车、退格和方向键，退格及方向键可以长按连发。上方保留常用 Vim 命令快捷栏。单指在终端内上下拖动可浏览回滚内容。多行剪贴板内容发送前会确认，并使用终端的 bracketed paste 边界；桌面端仍可直接使用物理键盘。字号与上次会话保存在当前浏览器。

可选配置 `TERMINAL_CWD` 指定新会话工作目录，未设置时使用第一个 `FILE_ROOTS`；`TERMINAL_MAX_SESSIONS` 默认为 8。终端继承 Allinone 进程用户的系统权限，不应将服务直接暴露到公网，建议使用 HTTPS、访问令牌和反向代理限速。

## 模块扩展

音乐下载、小爱同学音乐播放等功能均以独立模块实现，不与概览、文件和导航的内部状态混用。每个模块拥有独立的前端代码、API 命名空间、数据目录和错误边界；只复用鉴权、通用 UI 和安全校验等公共基础能力。详细边界见 `doc.md`。

## 安全提示

当前仅提供共享访问令牌，不是多用户账号系统，也没有暴力破解限速。不要把 2006 端口直接暴露到公网；对外部署应启用 HTTPS，并在反向代理层增加限速或访问控制。文件管理器可永久删除受控目录内的内容，网页终端还拥有运行用户的完整 Shell 权限。

更完整的架构与接口说明见 [doc.md](./doc.md)。

## 音乐文件编辑

音乐下载列表中点击“重命名”，输入不含扩展名的新名称即可保存；音频扩展名与文件内标签保持不变，同名文件不会覆盖。正在试听该文件时重命名会停止试听，可在新名称下重新播放。

音乐“元信息”支持读取、编辑和写入 MP3、FLAC、M4A 的内嵌歌词，最多 12000 字，可粘贴纯文本或 LRC；清空后保存移除歌词。自动刮削会为网易云候选尝试获取歌词（包括声音对应的音轨），选择候选后填入，点击“写入文件”才保存；其他来源暂不自动获取歌词。无歌词或请求失败不覆盖现有输入，时间轴能否滚动显示取决于播放器。

## 小爱定时与语音歌单

进入“音乐 → 小爱播放 → 定时播放”，先在顶部选择音箱，再添加命名歌单。可搜索该音箱本地曲库逐首加入，也可导入当前保存的播放列表，导入的是独立副本；支持移除歌曲、修改歌单名称和删除歌单。

选定歌单，填写每天的北京时间（例如 `21:00`）或语音提示词（例如“播放睡前歌单”），也可同时填写，设置播放轮数并保存。规则可以编辑、停用或删除。对选中的音箱说“小爱同学，播放睡前歌单”即可触发，需开启该音箱语音监听；提示词忽略空格、标点和英文大小写，整句匹配。触发会替换当前播放队列，沿用音箱当前音量。

定时由服务端执行，关闭网页仍有效；需要 Allinone 运行且音箱在线。每条规则每天最多定时尝试一次，离线或错过的时间不补播；执行情况显示在配置页，同一分钟每台音箱只允许一条启用的定时规则。支持最多 30 个歌单（每单 100 首）、50 条规则、1–20 轮。保存后自动生效，无需重启。正常启动使用 `npm start`，现有 PM2 部署使用 `npm run pm2:restart`。

语音歌单命中后会先等待小爱云端指令结束（必须实际收到云端响应，至少 2 秒，最后一条回复/云端播放指令后 0.8 秒），再接管本地播放，避免小爱原生音乐或电台覆盖歌单；等待中收到新语音或停止操作会取消本次播放，10 秒内没有响应或云端持续响应则记录失败。播放后若收到其他云端音乐接管指令，会清除本地剩余队列和切歌计时，避免稍后突然恢复；语音事件仅在 1 秒内去重，允许重新说提示词再试。

文件页点击右侧工具栏的“配置快捷目录”滑杆图标，每行填写 `名称:绝对路径`（英文冒号），支持 1–20 个已存在的目录，行顺序就是下拉框顺序。首次使用取 `FILE_ROOTS`，未配置时为 Home；网页保存后优先使用 `data/file-manager/config.json`，重启仍保留。删除入口不删除磁盘文件，对应收藏暂时隐藏，重新添加相同路径后可恢复显示。音乐下载目的地与终端默认目录不受此配置影响。启动仍使用 `npm start`，PM2 部署使用 `npm run pm2:restart`。

文件列表中点击文件旁“链接”先打开确认窗口，可选择打开方式及自定义后缀，点击“创建分享”后才生成免登录 URL；取消或关闭不会创建分享。已有分享直接进入设置，可复制同一链接或取消分享。仅分享单个文件，不暴露目录和管理权限，链接长期有效，取消后旧链接失效。默认在浏览器预览 HTML、文本、图片、PDF 和常见音视频，不支持预览的格式下载；可在分享设置中改为直接下载。对方需要能访问 URL 中的域名或局域网地址。重命名、移动、替换文件或移除其根目录可能使链接失效。分享配置持久化在 `data/file-manager/shares.json`，不会把整站访问令牌放进链接。

文件页右侧工具栏的“分享管理”图标可查看所有目录的分享记录，按最新创建在前显示文件名、路径、创建时间和当前可访问状态；支持复制链接、逐条取消分享和刷新。不可用的记录仍可取消，取消分享不删除文件。快捷目录配置与上传、视图切换等按钮统一位于右侧工具栏，手机端工具栏单独一行。

分享管理中的“设置”支持选择预览/下载、自定义 `/share/名称` 后缀（1–64 位英文、数字、短横线或下划线，以英文或数字开头，区分大小写）。保存新后缀后旧地址失效；清空后恢复原随机地址。HTML 预览支持内嵌样式、脚本和 data/blob 资源，不提供同目录资源访问，外部资源、联网、登录存储被沙箱限制，适合独立 HTML 文件。现有链接默认启用预览。

分享管理显示累计访问次数和最近访问时间，从功能上线后开始计数并持久保存；成功开始返回文件的 GET 请求计一次，刷新会再次计数，HEAD、错误请求和起点不为 0 的 Range 分片不计数。该数字不是独立访客数或下载完成次数，不保存 IP 或访客身份。

普通语音点歌（如“播放忽略不计”）和语音随机播放也使用云端等待接管：搜索命中后，至少等待 2 秒，并在收到的最后一条云端播报/播放指令安静 0.8 秒后发送 `stop` 停止云端歌曲，再播报数量和播放本地歌曲。成功时播报“好的，找到/随机播放几首歌曲”，提示结束后再播本地音乐；提示使用不自动恢复旧音乐的播放方式，期间继续拦截云端回复，只放行自身提示。失败提示仍保留。新的语音会取消旧点歌任务，等待超时会记录失败；网页点播仍沿用原流程。

云端歌曲拦截保留播放器 `stop`，防止云端歌曲抢占本地播放。已知限制：该指令不能可靠中断云端语音，会员提示仍可能与本地歌曲重叠；目前没有可靠的播报结束信号。临时诊断接口已移除。
普通语音点歌先按文字搜索；没有文字结果时，自动按不带声调、保留音节边界的拼音匹配歌名、文件名、歌手和专辑。完整歌名/文件名匹配优先，其次部分歌名/文件名、完整歌手、部分歌手、完整专辑、部分专辑；同级随机排列，按原搜索数量上限加入播放队列，不追问补充。网页搜索和语音歌单提示词保持原规则。启动或刷新曲库会自动补齐旧索引的拼音，无需重新解析未变化音频或重新下载歌曲。安装依赖后重启服务（`npm run pm2:restart`，普通启动为 `npm start`）生效；依赖缺失时日志提示，文字搜索和播放仍可用。

专辑标签为空时，文字和拼音搜索均以歌曲所在的直接父目录名作为专辑兜底，不改写音频标签。“安泊猜想”按 `an bo cai xiang` 建索引，因此语音识别成“安博猜想”也能播放该专辑；已有拼音索引在重启或刷新时自动升级。

停止音乐已内置“关机、关闭小爱同学、关闭音箱、把音乐关了、别唱了、不用唱了、不要放了、不听了、停一下”等常用完整指令；支持“小爱同学，请停止播放吧”等称呼、礼貌用语、句末语气词及标点。命中后停止本地播放、清空队列并取消切歌计时，不会到下一首时自动恢复。设置里的停止关键词作为附加指令保留；内置指令无需手动补到旧配置。只匹配完整停止表达，不把“关灯”“关闭空调”“播放别放了”当成停止。此功能停止音乐，不负责给硬件断电；小爱自己的关机语义仍由设备处理。更新后重启音乐 worker 或执行 `npm run pm2:restart` 生效，常规启动仍为 `npm start`。

音箱配置现在完整展示实际运行的内置停止关键词（只读并显示条数），下方可编辑最多 20 条附加停止关键词。内置词表位于 `modules/xiaoai-music/stop-commands.json`，随仓库版本维护；各音箱附加词保存在 Git 忽略的 `data/xiaoai-music/config.json`，清空附加词不影响内置指令。音箱服务离线、尚未取得词表时界面明确提示。

依据现存语音日志补充实际使用过的“停了”“别唱啦”；“闭嘴吧”由“闭嘴”加语气词规则覆盖，无需重复配置。关灯、关空调、晚安、知道了等表达不作为停止音乐指令。

## 健康数据

打开“健康”Tab，或访问 `http://127.0.0.1:2006/?view=health`。健康列表与导出文件均按日期从旧到新排列，同日期按记录 ID 升序；不完整日期沿用已有年/月精度归位。健康列表采用紧凑工具栏、分行指标单位和小型关注星标；日期始终显示并固定在最左侧，横向滚动指标时不移动，“编辑”入口位于日期下方。长文本默认最多显示三行，可点击“展开全文／收起”。日期下方“···”提供临时隐藏和删除：删除前确认人员、日期、来源及记录编号，删除后不再参与列表和导出；临时隐藏只保留在当前页面内存，按人员区分，不影响数据库和导出。点击“恢复隐藏行”恢复当前人员手动隐藏的记录，整页刷新也会清空；恢复后仍受关注列空行筛选控制。顶部可切换人员、添加人员和新增记录；每行“编辑”可修改全部字段，输入框上方可按字段名查找。日期选择精确到年月日；原表只有年、月、季节或注明待核的记录保留原说明，不补造日期，可在编辑时勾选“日期不完整或有待核说明”填写。

“显示列”只配置当前人员的列表字段，不修改数据；配置保存在数据库，刷新和换设备后仍有效。列名旁的 ☆ 可设为关注列（★ 再点取消），顶部“隐藏关注列全为空的行”统一控制筛选：仅当某行所有关注列均为空白或短横线占位符（含 `-`、`－`、`—` 等）时隐藏；数值 0 不为空。未设置关注列时显示全部记录。关注列与开关按人员存入数据库，未显示的关注列仍参与筛选，列表显示隐藏条数。筛选只影响列表，不删除记录，导出仍包含当前人员的全部记录。“导出 XLSX”默认导出当前人员全部列，也可选“当前显示列”。原表数字、文字、缺失标记和备注均保留；不自动判断指标是否异常。

多用户指多人健康档案，沿用全站登录，已登录者可访问全部人员，不包含独立账号或人员权限。无需新增环境配置或安装依赖。代码更新后使用 `npm run pm2:restart`，普通启动仍为 `npm start`，端口保持 2006。

终端底部快捷栏左侧的“原生 / 内置”（显示可切换的目标键盘）可直接切换输入方式，默认使用内置键盘，并在当前浏览器记住选择。原生模式会收起内置键盘并唤起系统键盘，可使用中文输入法；键盘收起后点击终端继续输入。两种模式均保留 Vim 快捷栏。前端改动刷新页面即可使用，启动命令仍为 `npm start`，地址为 `http://127.0.0.1:2006/`。
